The project files include routed 4 layer PCB board for a cassette intended to be used either standalone or
as part of a tower rack. The battery module includes:
- 4 lithium cells
- battery charge management
- overcurrent protection
- USB C PD negotiation
- cell balancing
- D-SUB interface

HW layout is production ready. SW includes skeleton generated using STM32 CubeMx.
